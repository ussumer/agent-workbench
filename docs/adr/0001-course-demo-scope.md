# 先按课程交付采购 Harness Demo

用户缺少配套 Java ERP 源码，希望尽快获得可学习、可演示的课程项目，因此选择自建采购库存 Mini-ERP，并尽量保留讲义技术栈和全部能力。虽然替换技术或删减模块可能缩短初期实现时间，但会偏离课程学习目标；任何调整必须事先讨论并获得用户同意。

当前技能进化按讲义实现，重点是技能创建、分配和持久化等生命周期能力。高级 RSI 研究留到后续，避免将论文实验、自动修改 Harness 和能力晋升系统变成本轮完成条件。
