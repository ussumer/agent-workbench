## 单章确认模板

```text
Part：
我的解释（3–5句话）：
我读过的核心函数：
一个失败案例及预期结果：
一个独立证据或测试断言：
剩余疑问：
我的决定：已理解 / 需要补充 / 暂时跳过
```

“已理解”不要求记住每个函数。要求能用具体案例串起机制，区分约束与假设，并能定位代码或证据。Part06可按技能、预算熔断、记忆归档分别确认。

后续反馈可以直接写“Part02需要补充：原子更新为什么比先查询后更新可靠”。先解决本章疑问，再由用户选择是否进入下一章；默认不逐题连续模拟面试。
