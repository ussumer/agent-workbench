# 学习空间基线

T44 验证公开条件变化确实改变独立裁判状态或最优目标，并设计操作差异；不执行模型学习，也不证明真实Actor有学习收益。`scripts/planning/learning_space.py` 是控制面代码，不能同步进 Actor 沙箱。

训练案例只暴露单个条件原子（交期冲突、预算部分满足、来源缺失、不允许分批）；测试包含训练中未出现的组合，例如交期+预算、交期+预算+缺失来源。每个案例绑定公开触发证据与 expected operation class，规则和案例文件以 SHA-256 记录。

反事实检查同时包含需要询问/拒绝/重算和不应询问/拒绝/重试的配对，避免策略退化成无条件先问、拒绝或重试。公开“可行性/约束/错误类别/规则 ID/证据引用”反馈由独立 judge 计算，禁止返回完整订单、offer、数量或私有最优方案。合法并列候选只要满足约束都可接受。

T44 通过只说明公开环境具有学习空间、反馈字段和隔离边界。还没有 Curator、候选生成、Snapshot/Promotion、真实模型训练、迁移收益或 TRACE 原论文完整复现；这些必须在后续任务单独验收并锁定费用。

报告有4个单条件训练锚点、4个公开组合/控制案例和5个严格单条件组反事实（预算、来源、分批、可行性预算、交期）。反事实右侧从左侧复制后只修改声明条件，保留其他公共字段；独立judge必须证明status或best改变，否则validate失败。缺信息状态unresolved与完整证据无解infeasible分开。候选Feedback区分硬约束失败与SUBOPTIMAL，不返回私有目标值或答案。这里的success仅为候选接受，不是ERP写单或最终Episode成功。真实Actor校准仍未运行，报告明确proves_actor_learning_space=false。
