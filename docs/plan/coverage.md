## 解释材料矛盾，不能静默删能力

- PDF 第7/10/12页强调Store持久化，24-25页部分图却写InMemoryStore。已确认跨重启恢复，因此实现Mongo-backed Store；保留官方StoreBackend。笔记“存在内存里”不是最终存储要求。
- PDF 第7/26页技能namespace为`('skills',)`。保持该逻辑命名空间，用户生成技能在key前缀隔离，不能只靠middleware名字声称已经隔离。
- PDF 第27页扫描有metadata缓存，28页说下一次对话使用新技能。因此按revision在下一次调用刷新，不虚构当前run热加载。
- YAML弹性扩展不等于运行中热加载；新增配置重建graph后生效。
- PDF 第3页tool_error.py已废弃，不恢复第二套吞错逻辑；摘要工具中间件来源标注存在不一致，以锁版实际API核验，能力保留。
- 并行task、沙箱预热后台任务和异步Protocol子Agent是不同机制；本方案保留笔记中的异步功能。
- 26种图表是讲义当时目录；要保留多图表统一入口和课程所需类型，对上游目录变化留记录，不造工具充数。
