# T44 学习空间基线与独立反馈契约

## 目标
在创建 Curator 或申请付费模型前，证明公开采购环境存在可学习的操作策略：训练只暴露原子条件，测试重组条件；反事实改变应触发不同动作；独立裁判反馈可归因、可复核且不泄露完整答案。

## 前置与必读
T37/T38/T40/T41/T43；execution/HANDOFF；场景升级提案、自进化规格、论文核查、planning契约。先 check → next → packet。

## 文件边界
scripts/planning/learning_space.py、tests/acceptance/test_t44.py、fixtures/planning/decision-cases-v1.json及学习空间运行说明；不改独立评测工作区，不调用付费模型，不实现Curator/晋升。

## 实现步骤
定义公开 rule atom、train/test split、未见组合和反事实对照；每个案例绑定可观察条件、预期操作类别及来源 hash。用独立 judge 只在控制面计算可行性/目标，生成白名单 Feedback（success、约束分类、error_categories、rule_ids、证据引用），不输出订单、offer、完整计划或私有最优解。验证不同合法方案可并列接受，缺信息与不可行分开，动作不存在一律询问/拒绝/重试的反例。

## 验收条件
至少12个零模型检查：原子训练覆盖、测试组合训练未出现、反事实正负动作、来源/规则 hash、公开字段完整、答案与凭据不泄露、独立裁判状态可复核、缺失与不可行分离、合法并列方案、未知规则拒绝、报告可重建。命令生成带 hash 的学习空间报告；失败保留。

## 检查命令
python3 scripts/gate.py T44

## 失败处理
学习空间不足或反馈泄露时保持任务失败，不能修改评分使其通过；不登记Curator或学习增益。

## 完成证据
完整gate receipt、报告hash与JUnit；明确只证明可学习环境和反馈接口，不证明真实模型学习率或TRACE原论文复现。
