# T16 预置抓取分析技能与报告下载

## 目标

主子Agent利用技能在沙箱抓取、计算并交付真实报告。

## 实现步骤

1. 补齐各预置SKILL.md、抓取/HTML转换脚本、分析模板和URL映射。
2. 按两种HTML抽取报价，Decimal计算补货，保留来源时间和缺报价警告。
3. 生成Markdown/CSV，调用统一图表入口；报告字段完整，不虚构供应商事实。
4. 实现sandbox产物转存、元数据、受归属保护下载和图表资产加载。
5. 测试无报价/解析错误/文件不存在/路径越界与跨用户下载。

## 验收条件

- 最低价推荐与2553.00总额正确；trace证明从HTTP抓取而不是仅查seed。
- 报告及图表真实可下载，文件hash匹配，缺产物不发假链接。
- Agent按需读SKILL.md和执行脚本，有失败路径。
- 对应 tests/acceptance/test_t16.py 必须运行且断言数不少于 12 个测试用例；数量只是防零收集底线，不能代替上面的行为覆盖。
- 所有 required checks 通过；不能跳过真实服务测试后登记完成。
