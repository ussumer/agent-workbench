# T05 报价站与技能下载资源

## 目标

补齐课程缺少的报价网站和可下载技能包。

## 前置与必读

前置任务：[T01](T01.md)。需求：R05。

- [contracts/external.md](../contracts/external.md)
- [contracts/skills-memory.md](../contracts/skills-memory.md)

## 文件边界

- fixtures/site/、fixtures/skills/
- infra/compose.yml
- tests/acceptance/test_t05.py

允许补充本任务所需小型测试/配置；不要重构无关模块。最终向用户报告真实文件路径，不保留本文目录中的省略号作为实际路径。

## 实现步骤

1. 创建独立真实HTTP服务，两个供应商采用表格/列表HTML，价格来自seed。
2. 生成合法技能ZIP、catalog和内容hash；技能脚本使用固定JSON输入输出。
3. 提供仅测试可用的慢响应、500、无报价页面和坏ZIP fixtures。
4. 验证宿主访问，记录预计沙箱可用地址；容器内访问在T08继续验证。

## 验收条件

- 两站内容和技能包真实HTTP可读，显式标记演示数据。
- ZIP有frontmatter、脚本和样例，sha256与catalog一致。
- 最低价合计2553.00，新技能算例1533.00。
- 对应 tests/acceptance/test_t05.py 必须运行且断言数不少于 10 个测试用例；数量只是防零收集底线，不能代替上面的行为覆盖。
- 所有 required checks 通过；不能跳过真实服务测试后登记完成。

## 检查命令

```bash
python3 scripts/gate.py T05
```

gate 的实际 argv 和报告路径以 ../tasks.json 为准；不得为本包手工编造 passed receipt。

主验收模式：integration。fake 只准用于声明的 unit/integration 模型替身，live 模式禁止。测试标准见 [verification](../verification.md)。

## 失败处理

不能使用课程私人IP；网络不通先解决容器路由，不把报价直接内嵌Agent。
