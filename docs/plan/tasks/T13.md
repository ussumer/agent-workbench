## 实现步骤

1. 按契约创建chat/resume/state/history/cancel与演示session端点，处理归属和request_id去重。
2. 集中归一化v2 messages/values和子图namespace，聚合工具参数、结构化内容和todos。
3. 持久化展示消息/中断后发送done，run生命周期使用registry而非悬空task。
4. 前端断开后状态可查询，API进程重启时对账checkpoint/未知写结果。
5. 测试UTF-8分片、工具参数碎片、重复事件、迟到token、异常终结和历史删除。

## 验收条件

- 每run只有一次done；interrupted不能当completed，error后不能显示成功。
- 刷新可读pending_interrupts；同request重发不启动新run。
- 历史不因摘要丢失，删除不删除用户技能/订单；其他用户访问404。
- 对应 tests/acceptance/test_t13.py 必须运行且断言数不少于 18 个测试用例；数量只是防零收集底线，不能代替上面的行为覆盖。
- 所有 required checks 通过；不能跳过真实服务测试后登记完成。
