# T55 GDPevo 真实文字技能训练与固定消融

## 目标

在训练前冻结提交 `9f2ea2e` 的任务集上，执行一次受预算限制的真实 GDPevo 文字技能训练：五个 train 任务、至多一次诊断重试、一次真实 Curator，再对五个 held-out test 做 retrieval/raw 与 curated 两组固定消融。生产 Harness 技能指针保持不变；结果用于简历项目的真实管线证据，不把一次小样本描述性对照写成学习收益。

## 前置与必读

阅读 `docs/plan/execution.md`、`docs/plan/HANDOFF.md`、T53、任务集说明和预算网关实现。

## 前置与边界

前置 T53。模型身份从现有配置读取为 `deepseek-flash`，无工具、temperature=0、thinking disabled；每次模型调用经既有预算网关，累计上限 50 CNY、单次 attempt 上限 2 CNY。只读复核已有外部运行目录，不重复调用。T54 留给任务集扩展，不在本包修改其文件。

## 文件边界

新增 `scripts/planning/gdpevo_training.py` 与 `tests/acceptance/test_t55.py`，记录本任务说明、状态、HANDOFF 和 gate receipt；保存实验技能 `fixtures/planning/gdpevo-text-skill-v1.json` 和结果报告 `docs/runtime/gdpevo-training-2026-10-04.md`。外部运行目录保存冻结输入、请求、响应、usage、失败重试、Curator、两组 bank、评分和 manifest；不修改生产 Harness 活动技能。

## 实现步骤

1. 固定并核对训练前提交、任务集 hash 和模型配置。
2. 运行已有训练脚本；失败保留，最多一次诊断重试；完成一次 Curator 和两组 held-out 消融。
3. 只读验证外部运行目录、manifest、请求边界、评分和账本，登记 gate 证据。

## 验收条件

1. 单元测试断言训练/Curator 不能读取 test、raw 不泄漏 test、消息边界和六字段 rubric。
2. `gdpevo_training.py verify` 只读核验 manifest、模型/调用数、请求边界、私有评分、Curator 输出和两组各五题完整性。
3. 报告保留失败并准确区分组件/内容结果与生产 Actor 能力；未观察到训练增益时停止新增调用。

## 失败处理

网络或依赖问题出现两次即停止，不重复启动相同失败命令；业务分数低或无增益不通过修改评分解决。
