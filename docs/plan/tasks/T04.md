## 实现步骤

1. 用官方MCP SDK FastMCP注册八个工具并启动Streamable HTTP；httpx池在lifespan管理。
2. 实现参数schema、结果envelope、错误类型与有限重试。
3. 实现每次调用的身份和内部授权接口；T12最终接入审批记录，此阶段拒绝无授权写，测试用明确隔离的授权stub。
4. 用MCP客户端做tools/list和八工具调用，断开重连，验证HTTP业务结果。
5. 保存工具名称和schema快照；验证分析/订单角色预期集合。

## 验收条件

- 工具目录恰好八个ERP工具，schema不暴露actor、token、operation_id。
- 业务4xx/断网/超时不变成空列表成功；读重试有界，写用同key。
- demo-a/demo-b并发调用身份不串；连接退出关闭。
- 对应 tests/acceptance/test_t04.py 必须运行且断言数不少于 12 个测试用例；数量只是防零收集底线，不能代替上面的行为覆盖。
- 所有 required checks 通过；不能跳过真实服务测试后登记完成。
