# T36 面试项目分章学习文档与确认记录

## 目标
用户已有项目整体脉络，提供分part的机制学习文档，逐章自主确认，不逐行讲解或连续模拟追问。

## 前置与必读
T35；architecture、review、verification；核对代码与历史证据的实际边界。

## 文件边界
docs/learning/、scripts/check_learning_docs.py、docs/plan/review.md与计划交接。

## 实现步骤
入口与学习确认表，七章具体机制；每章解释业务因果、实际代码入口、有限阅读范围、案例、自检及面试表达。区分当前实现和建议，保持诚实贡献说明，不自动勾用户确认。

## 验收条件
实现并运行本地文档链接/章节结构检查；必要入口/七章/确认记录齐全，所有源码相对链接存在，所有章节包含学习目标、代码阅读、自检、确认。该检查仅文档，不声称应用、渲染或用户掌握通过。

## 检查命令
python3 scripts/gate.py T36

## 失败处理
修正文档错链及错误说明，保留失败收据，不运行无关服务或修改应用测试。

## 完成证据
command gate receipt与state/HANDOFF；review保持not_reviewed，用户学习状态仍待确认。
