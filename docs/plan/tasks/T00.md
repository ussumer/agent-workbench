## 实现步骤

1. 核验工具与官方包元数据，按依赖规格解析并锁版本；对未配置凭据只输出缺项名称。Java使用完整JDK或项目构建容器。
2. 创建讲义对应目录、Python package、Java空服务、Vue工程；最小健康检查不能冒充后续业务能力。
3. 实现 gate 参数数组执行、超时、JUnit/JSON解析、attempt目录和receipt；manifest中每个required check都必须运行。
4. 实现doctor和服务启动说明；Compose持久卷、网络、端口有单一配置。把OpenSandbox控制服务的特殊启动要求列明。
5. 用临时子进程测试gate：成功、失败、零测试、跳过、缺命令、超时、缺配置、日志脱敏。记录resolved版本组合。

## 验收条件

- 冻结安装可重复，Java和Vue骨架能构建；不存在latest浮动依赖作为最终锁。
- gate对零测试、mandatory skip和缺凭据不返回passed；8类负向/正向行为实测。
- doctor不输出密钥；现有讲义笔记未被覆盖。
- 对应 tests/acceptance/test_t00.py 必须运行且断言数不少于 8 个测试用例；数量只是防零收集底线，不能代替上面的行为覆盖。
- 所有 required checks 通过；不能跳过真实服务测试后登记完成。

## 检查命令

```bash
python3 scripts/gate.py T00
```

本包负责先实现 gate.py，再用它检验自己。所有应用命令在本轮方案交付时尚未实现。

主验收模式：unit。fake 只准用于声明的 unit/integration 模型替身，live 模式禁止。测试标准见 [verification](../verification.md)。
