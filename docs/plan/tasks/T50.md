# T50 规划目标异步只读审查上下文

## 目标
让异步分析子会话在需要时核对同一规划目标的 revision、约束、来源状态和已创建订单，输出审查报告；不获得订单写权限，不替换主 Actor。

## 前置与必读
T49/T20；execution/HANDOFF、external 与 planning 契约。

## 文件边界
src/agent/async_tasks/service.py、infra/agent-protocol/analyst_graph.py、src/api_view/internal/analysis.py、src/api_view/web_main.py；测试与运行说明。

## 实现步骤
通过官方 Protocol 输入传递 owner/thread 上下文；主进程内部 token 路由提供 owner-scoped 的 planning_goal 只读数据。异步 graph 仅在规划审查指令下读取该数据，报告 revision、受影响来源和订单状态；库存分析路径保持原行为。

## 验收条件
跨 owner/thread 不可借读；规划审查不调用写工具、不创建订单；Protocol 重启/不可达仍按现有状态语义；既有库存异步回归不变。

## 失败处理
缺目标返回可见未找到，不伪造完成；保留失败尝试。超过两次有依据修复或约20分钟无进展即停止讨论。

python3 scripts/gate.py T50

## 完成证据
异步上下文/权限单测与既有真实 Agent Protocol 回归。
