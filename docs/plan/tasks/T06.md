## 实现步骤

1. 仅从配置读取实际模型ID/URL/协议；探测中文响应和工具调用，保存脱敏结果。
2. 实现CAP-01..08最小实验，含流式工具分片、子图中断恢复、Mongo重启读回、真实沙箱I/O和最小异步服务调用。

4. 把resolved依赖标记verified并冻结；记录课程示例与安装API的适配差异。

## 验收条件

- 八项CAP都有实际结果，不能以import成功代替工具调用/沙箱运行。
- 所有后续构造接口有固定版本依据；真实模型调用不走fake。
- 缺凭据为blocked，错误诊断不泄露key。
- 对应 tests/acceptance/test_t06.py 必须运行且断言数不少于 8 个测试用例；数量只是防零收集底线，不能代替上面的行为覆盖。
- 所有 required checks 通过；不能跳过真实服务测试后登记完成。
