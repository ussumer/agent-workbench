## 实现步骤

1. 创建Mongo客户端生命周期、官方checkpointer/store实例、应用集合索引。
2. 实现线程归属、展示消息upsert、run请求去重、pending_actions存储接口，不把展示历史当checkpoint。
3. 实现用户namespace和skills key前缀限制；内存实现仅用于unit fixtures。
4. 写入后关闭进程/客户端重启，恢复图状态、偏好与技能文件；测试其他用户访问失败。

## 验收条件

- Mongo真实重启/新进程读回，namespace隔离通过。
- 重复消息和request_id不会生成重复记录，不同正文同ID冲突。
- 测试清理不涉及开发库；有明确collection/index清单。
- 对应 tests/acceptance/test_t07.py 必须运行且断言数不少于 12 个测试用例；数量只是防零收集底线，不能代替上面的行为覆盖。
- 所有 required checks 通过；不能跳过真实服务测试后登记完成。
