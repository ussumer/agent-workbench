# T18 长期偏好与自动采购记忆

## 目标

保留课程显式偏好、采购历史自动更新和跨会话使用。

## 实现步骤

1. 定义四偏好和两历史字段schema，默认初始化，结构化存储生成preferences.md。
2. 识别用户明确偏好，校验支持值，只有成功ERP相关任务自动更新recent字段。
3. 注入主Agent，并明确传给子Agent；限制历史条数和内容大小。
4. 测试用户新thread/API重启、闲聊不更新、网页指令不能改偏好、不同用户隔离。

## 验收条件

- demo-a要求表格后新会话和子Agent遵循，demo-b保持默认。
- 自动历史不覆盖显式偏好，不把失败/拒绝当采购成功。
- 外币请求不假换算；Mongo跨进程保存可核对。
- 对应 tests/acceptance/test_t18.py 必须运行且断言数不少于 12 个测试用例；数量只是防零收集底线，不能代替上面的行为覆盖。
- 所有 required checks 通过；不能跳过真实服务测试后登记完成。
