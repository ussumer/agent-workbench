# T49 Vue持续目标修订与重新审批入口

## 目标
用户在同一规划会话修改预算、需求与交期、选择物料刷新来源，保存新版本并继续规划。旧审批从界面撤下，既有订单保留，新候选需重新审批。

## 前置与必读
T48/T43/T42；execution/HANDOFF、planning契约。复用现有PATCH goal与正式chat，不另造planner或运行时。

## 文件边界
frontend/src/components/PlanningGoal.vue、api/client.ts、App.vue；对应组件与交互测试。

## 实现步骤
复用目标表单增加修订模式，固定物料身份；发送expected_revision和选择的refresh_part_ids。展示受影响物料、保留原订单。修订成功清理旧审批，提供同线程继续规划入口；冲突保留输入并要求刷新，不自动覆盖。

## 验收条件
UI能修改预算/交期/需求并按物料刷新，错误时保留旧目标和编辑输入，活跃运行/不确定写入时禁止修改；新版本清除旧审批而不清除历史，继续规划通过原stream接口。Vue测试与生产构建通过；真实Mongo/Java/MCP的既有对应revision API行为通过，不声明新增live模型学习收益。

## 失败处理
保留失败证据；两次有依据修复仍失败或20分钟无进展停下讨论，不重复付费消融。
