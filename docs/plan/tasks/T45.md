# T45 独立反馈持久归档与真实基线闸门

## 目标
把 T44 的独立反馈作为控制面记录绑定到真实 Episode；成功/失败对照可追溯、不可重复覆盖，Actor不能写入或读取私有裁判。为未来真实 Actor 基线提供费用/模型/服务前置检查，但本包不调用模型。

## 前置与必读
T44；execution/HANDOFF、学习空间基线、自进化规格、planning契约。先 check → next → packet。

## 文件边界
src/agent/evolution/feedback.py、tests/acceptance/test_t45.py、必要运行说明；只修改现有Episode集合，不新增替代存储，不触碰独立评测工作区。

## 实现步骤
定义严格Feedback白名单（success、constraint/environment status、error categories、rule IDs、evidence refs、evaluator/report hash）；owner/episode/run归属从控制面取，CAS只允许空feedback写一次，事件与hash可导出核对。拒绝答案、订单、报价、数量、凭据和未知字段；重复或跨owner写入失败。提供真实基线配置检查函数，确认模型身份、端点、服务和预算字段齐全；缺配置返回blocked/不发起调用。

## 验收条件
至少12项unit和8项真实Mongo integration：白名单/类型/敏感字段、hash与重启读回、owner/episode/run fencing、CAS重复写、事件缺失回滚/不伪造成功、Actor不可见接口、模型预算配置不猜ID；T44/T41回归不降级。无模型调用，不能把组件通过写成学习增益。

## 检查命令
python3 scripts/gate.py T45

## 失败处理
保留失败attempt；反馈不完整或归属不明时保持未评分，不自动修复成成功。真实模型费用需另行明确总额度后执行。

## 完成证据
receipt/JUnit与反馈哈希；明确只证明可持久化独立反馈和基线闸门，不证明Actor学习或TRACE论文复现。
