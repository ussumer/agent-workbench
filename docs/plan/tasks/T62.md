# T62 操作级 TRACE 反馈与 Curator 输入

## 目标

把 T61 的真实 text/compute 对照转换为可审计的操作级反馈材料：保留公开题目、Actor 输出、每次 OpenSandbox 执行的状态/版本/read_names/saved_names 和独立评分失败字段，生成 train-only Curator 请求。该包不调用模型、不读取私有 rubric/答案、不晋升技能。

## 验收

- 四行 T61 结果全部保留；compute 轨迹必须逐操作核对 completed、持久 task 读取和版本递增。
- text 行没有伪造工具操作；compute 行不丢失代码 hash、读写声明或执行状态。
- Curator 输入只含公开 task、Actor 输出和反馈，不含私有答案、rubric、gold、manual_checks。
- 生成过程零模型调用、不可覆盖已有输出、manifest hash 可重放；报告明确 `learning_gain_proven=false`。

## 前置与必读

T61；`docs/plan/execution.md`、`docs/plan/HANDOFF.md`、T61真实attempt、TRACE论文原文。不得恢复T59/T51，不得读取私有控制文件。

## 文件边界

新增零模型反馈打包脚本、协议测试、任务与交接登记；只读外部 T61 attempt，不改生产 bank、ERP、评分器或历史 attempt。

## 实现步骤

1. 校验 T61 manifest 和四行公开结果，提取 text/compute 的 Actor 输出与独立评分失败字段。
2. 对 compute 逐操作保存状态、版本、read_names、saved_names、代码 hash 和完成状态，确认持久 task 被显式读取且版本连续。
3. 生成仅含 train 公开资料的 Curator 输入；text 不伪造工具轨迹，报告不宣称学习收益。

## 验收条件

四行结果齐全；两条 compute 轨迹全部 completed 且持久 task 读取成立；输入不含私有 marker；重复 prepare 拒绝覆盖；verify 只做 hash 校验，零模型调用。

## 检查命令

`python3 scripts/plan_guard.py check` → `next` → `packet T62`；执行 `python3 scripts/gate.py T62`。所有检查均为零模型。

## 失败处理

历史 manifest、任务 split、版本链或工具状态不一致立即失败并保留输出；不通过修改输入、评分或补造 trace。遇到同一问题两次修复失败或约 20 分钟无进展即停止。

## 完成证据

gate receipt、Curator 输入及 manifest、8 个以上协议测试、Git commit 和 HANDOFF 登记。该包只补反馈边界，不等于 Curator 训练或学习增益。
