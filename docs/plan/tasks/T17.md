2. 创建reorder-cost-summary示例；沙箱实际测试，失败反馈模型最多修复两次，保存每次结果。
3. 实现版本manifest、Store完整文件写入/读回、发布指针条件更新和内容去重。
4. assignment后刷新skills_revision，最迟下一次调用发现；恢复时校验hash。
5. 测试ZIP穿越、坏脚本、Store半写、重复发布、不同scope、清理、重启和重建沙箱。
