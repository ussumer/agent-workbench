## 实现步骤

1. live启动自检拒绝fake，记录脱敏模型ID和外部服务配置。
2. D01-D08各跑3次，保存全部尝试、轨迹、断言和产物；自动测试客户端代替人点击approve须明确标测试操作者。24个trial结果与pytest结果分开，按verification.md使用逐例关键不变量和分组/整体门槛断言，不用skip掩盖失败，也不在每条断言中重复运行模型。
3. 独立数据库/Store/文件核对业务结果，Playwright用真实后端完成演示。
4. 搜索至少1次、柱状/折线/饼图资产有效；下载技能路径另做真实演示。
5. 失败保留并归类，修复代码后新建完整轮次，不挑选历史成功样本拼报告。

## 验收条件

- 24次至少22成功、每案至少2/3；关键写权限/金额/幂等/隔离全部通过。
- 真实搜索与3类图表可用，报告和技能有非空可检验内容。
- 桌面移动截图资产正确、界面无重叠；没有固定回复或假工具轨迹。
- 对应 tests/acceptance/test_t23.py 必须运行且断言数不少于 24 个测试用例；数量只是防零收集底线，不能代替上面的行为覆盖。
- 所有 required checks 通过；不能跳过真实服务测试后登记完成。
