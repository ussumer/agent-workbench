## 实现步骤

1. 实现Order/Line/Operation和原子事务，BigDecimal金额校验；owner只取可信内部身份。
2. 实现创建、列表/详情、整单修改，expected_version并发条件更新。
3. 保存原始HTTP字节hash、类型、目标和成功结果；处理唯一键竞争后重新读取提交结果。
4. 错误路径事务回滚，不能留下半张订单或只写Operation；不改库存。
5. 测试两线程同key、不同body同key、响应丢失重试、并发修改和不同用户查询。

## 验收条件

- 50件25.50=1275.00；改60件=1530.00且version=2；库存仍为8。
- 并发/重试同key只有一单；不同body同key409；两个旧版本修改只有一个成功。
- 无效供应商/供货关系/金额/数量、越权请求零写。
- 对应 tests/acceptance/test_t03.py 必须运行且断言数不少于 18 个测试用例；数量只是防零收集底线，不能代替上面的行为覆盖。
- 所有 required checks 通过；不能跳过真实服务测试后登记完成。
