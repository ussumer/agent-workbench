# T25 修复开发会话的数据保留和重启验收

## 目标
修复评审 F01：开发会话启动、关闭、异常退出不得清空 MongoDB，真实 ERP 订单和 MongoDB 记录重启后仍可读取。

## 前置与必读
前置任务：[T24](T24.md)。需求 R28。阅读评审报告、ERP 契约和 verification。

## 文件边界
scripts/dev.py、tests/live/stack.py、tests/acceptance/test_t25.py、tests/acceptance/test_t24.py、docs/runtime/runbook.md，以及本任务计划状态和交接。

## 实现步骤
1. 为同一真实栈增加显式保留模式，测试默认继续清空独立测试库。
2. dev.py 启用保留模式；无固定数据库或目录的保留请求必须拒绝。
3. 使用独立目录和数据库运行真实服务，写入 MongoDB 记录和 Java ERP 订单，重启验证内容及幂等状态。
4. 验证临时模式在正常和异常退出时均清理；修正文档中无效的重启证明。

## 验收条件
真实记录在关闭后和第二次启动后存在；ERP 订单内容及操作幂等保持。测试默认清理不退化，保留模式不隐式用于其他验收。不使用内存数据库或 ERP 固定返回替代。至少三个测试且没有跳过。

## 失败处理
缺少真实服务或配置记录 failed/blocked 收据，不登记 done，不修改历史通过证据。
